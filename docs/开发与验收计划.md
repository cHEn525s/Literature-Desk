# 开发顺序与验收门槛

**当前停点为架构评审。** 下表为确认后的工作顺序，所有联通、下载和安装用例均待执行。验收记录应注明实际版本、样本来源、观察结果和阻塞原因。

| 阶段 | 最小交付 | 进入下一阶段的条件 |
|---|---|---|
| 1　隔离联通 | 在临时 Zotero 配置和测试库中加载最小桥接；用固定的虚构任务文件握手、列分类、导入一个测试条目、挂接两个分类、列举一份可用测试 PDF | 记录真实版本和能力；同一命令提交两次仍只有一个条目和两个成员关系；EXE 可读取回传附件；第二个桥接实例不能获得运行锁 |
| 2　下载与续跑试验 | 在隔离库用一条已知可取得的 DOI 验证实际下载和附件回传，再试一次批次暂停和手动继续 | 能确认附件可读；暂停后保存停点，用户点击“继续”后仅处理未完成项 |
| 3　桌面与导入 | 文件选择、Excel 映射、Bib 原文保留、身份映射、批次状态库、本地复用 | 两个样例均能全量追溯；冲突可逐项复核；重复任务及崩溃恢复用例通过 |
| 4　核验与交付 | 统一本地/下载核验、人工复核、暂停恢复、分组缺件与机器清单 | 下列交付对账及故障用例通过，完整快照可供另一个程序独立读取 |
| 5　Windows 发行 | 构建 Setup.exe 和内含的桥接 XPI，完成首次使用向导 | 另一台 Windows 电脑从安装到样例交付走通，记录已测兼容组合 |

### 验收用例

| 用例 | 操作 | 通过条件 |
|---|---|---|
| 两个真实输入 | 一起导入 8-134.bib 与 C34_肺癌_Chen.xlsx，选择“纳入记录”，给两组指定同一父分类及不同子分类 | 预览及清单共 616 行，分组为 134 / 482；Bib 显示 46 个 DOI 字段，88 条无 DOI 记录从原 URL 提取 PMID。逐行比对 Excel 全部九列，包括分工和是否纳入，源文件前后哈希相同 |
| 原格式往返 | 选不同缺件行，含 Bib 嵌套字段、宏、自定义字段和 Excel 空白值、文本型编号；重读缺件文件 | 顺序与字段逐条一致，Bib 宏可解析；Excel 类型和来源记录号一致。输入同名、键重复、前缀相同均能定位，导出无覆盖 |
| 跨组同篇 | 两个组各放一条同篇题录，以可靠 DOI 或明确的 DOI↔PMID 对应连接，只在其中一个条目挂正确正文 | 一个 work_id、两个 record_id、两个分类成员关系、一个交付 PDF；两组取得各加一，下载调用零次；移去测试候选再运行同等条件的新批次，最多调度一次下载 |
| 同名冲突 | 输入同题名但 DOI 矛盾的两条记录，另给仅含 PMID 且无可靠 DOI 对应的记录 | 前两条进入复核且无交叉回填；后一条先尝试本地复用，缺少下载必需 DOI 时单列原因，保留原始记录 |
| 基本交付核验 | 分别提供正确正文、明显错文和损坏附件 | 仅正确正文计入取得；其余记录标明原因，后续工作流可从逐条清单接手 |
| 分组对账 | 构造 add_1-589.bib 的 588 成功/1 缺件场景，另设全成功组、全缺件组及组内重复 | 缺件文件名 add_1-588-1.bib 且恰含一条；全成功组未取得为 0，无空文件；全缺件组原记录全部导出；逐行路径和哈希能和唯一 PDF 交叉核对 |
| 无人值守长跑（建议门槛） | 在隔离环境中按固定节奏持续运行 24 小时，混合取得与单篇未找到两种结果 | 正常队列持续推进，单篇未找到后继续，已核验项无重复下载，最终交付对账通过 |
| 真实通道观察 | 在实际插件上运行经确认的跨夜批次 | 报告实际运行时长、已取得数和剩余数；若批次暂停，记录停点并等待用户继续 |
| 人工验证与暂停 | 分别在用户主动暂停、验证阻塞时重启程序，随后点击“继续” | 暂停状态持久保存；重启或关窗后无新下载，用户点击“继续”才核对进度并接着处理 |
| 中断与重启 | 分别在写命令临时文件、绑定完成未收回执、下载返回未回报、PDF 复制中、快照发布前终止对应进程；重开 Zotero 与 EXE，再重复投递同一回执 | 半写文件不消费；原绑定可定位，结果未知先对账；无重复建项、重复计数或自动重复下载。旧完整交付仍可打开，重新结算后逐项哈希相符 |
| 并发与兼容 | 启动第二个 EXE 或桥接实例，切换到不同库、旧握手或不支持的协议/插件组合；另测任务目录无写权限 | 显示占用方或具体配置原因；活跃批次不被抢占，不向错误库写入；修正配置后可恢复 |
| 异机首装 | 在无开发环境、无个人配置的另一台 Windows 电脑，先测试缺前提提示，再准备所测版本 Zotero 和原插件。安装 Setup.exe，从向导安装 XPI，使用带中文及空格的目录，测试一次本地复用及一次受控下载，重启后再打开 | 只需 Setup.exe 及说明的既有前提；快捷方式和 XPI 均可用，识别本机库；导出目录、汇总、逐条清单和 PDF 齐全。检查发行包内无样例附件、批次日志、凭据或个人路径 |

**评审请确认**　优先验收正常队列长时间连续获取、暂停时保存进度和人工继续。建议以 24 小时可控长跑加真实插件跨夜观察评估稳定性；错件补下载留给后续工作流。
