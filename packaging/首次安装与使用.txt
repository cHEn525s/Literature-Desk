Literature Desk 1.2.0　｜　Windows x64 首次安装与使用


从已有版本升级
使用原 Windows 账户，关闭桌面端后运行 Setup.exe。打开「打开历史批次」，按原文件、时间和取得数选回已完成或已中止的整批记录。点「只重跑未取得」，核对保留篇数和待重跑篇数，再连接专用 Zotero 并点「开始」。新导出累计原始整批的结果。重新导入缺件 Bib 或 Excel 会创建独立批次。

取得数按能打开的 PDF 统计。绑定到题录的摘要、扫描件也可计入，正文身份与完整性留给后续审核。同一条目有多份不同 PDF 时，其他文件在「同条目其他PDF」中，并在逐条结果中关联。散放在本地目录的 PDF 仍需先匹配到题录。

安装
1. 准备 Windows 10 或 11 的 x64 电脑。本机已验证的组合为 Zotero 10.0.8 和 Sci-Hub 插件 2.0.1。先在 Zotero 的插件管理器中确认已有下载插件。
2. 双击 Setup.exe，按向导为当前 Windows 用户安装。程序自带 Python 运行环境及 PDF 读取组件。快捷方式默认不勾选。安装结束时可直接打开工具；以后可按 Win+R 并输入 %LOCALAPPDATA%\Programs\ZoteroFullText\LiteratureDesk.exe 启动。若更改安装路径，请从所选目录启动。
3. 点击“连接专用 Zotero”。首次连接会将随包的桥接 XPI 和本机已有下载插件加载到工具专用配置。若 Zotero 安装在自选目录，请在提示框中选择 zotero.exe。稍候，界面应显示“专用库已连接”。

用一小批文献验证
4. 点击“选择文件”，选一份 BibTeX 或 Excel 题录。输入本批父分类名。Excel 可选中表格行后点“分组与列映射”设置工作表及标题、DOI、PMID 等列。
5. 如有已知匹配的本地正文，添加其所在的“本地 PDF 目录”。点击“导入预览”，核对组名与原始条数。点击“开始”。
6. 建议用一篇可获取 DOI 验证新下载，再用另一篇带本地正文的记录验证复用。多篇时可点“暂停”，待当前项结束后关闭桌面程序，再次打开后点“继续”。若通道需要人工验证，在专用 Zotero 内处理后再继续。
7. 点击“导出交付”，选择可写目录。打开新生成的交付文件夹，检查“正文PDF”“未下载题录”“分组汇总.csv”“逐条结果.jsonl”。每组取得数加未取得数应等于原始条数。全组取得时汇总显示 0 条缺件。

首次验收可记下 Windows、Zotero、下载插件版本，以上各步是否通过及错误提示。24 小时跨夜稳定性尚未完成验收。

位置
桌面程序按当前用户安装；批次、专用文库和进度位于 %LOCALAPPDATA%\ZoteroFullText\workspace。程序目录的 bridge 文件夹包含自研 XPI。已经导出的交付位于你选择的目录。通过 Windows“已安装的应用”卸载软件，用户工作区及已有导出会保留。

中止任务后可导出当前结果，再选择其他文件。尚未完成的记录原因标为 batch_aborted。已提交的单篇调用可能自行结束。
文库位置按钮可查看实际目录。迁移前请关闭专用 Zotero，选择目标盘的父文件夹，等待复制、校验完成后重新连接。首次连接前也可选位置。原件保留至自行核对清理。
已中止或已完成的批次，可点「用原题录新建批次」，核对后点「开始」。连接时会显示实际文库路径；已连接时再次点击会请求显示专用 Zotero 窗口。只重跑未取得：批次完成或中止后，点击“只重跑未取得”，再点“开始”。新批次保留已有且校验一致的正文，重新处理其余论文（包括中止前尚未处理的论文）。导出交付包含整批累计结果。

首次使用或换网后，先测试下载地址

「专用库已连接」表示 Literature Desk 已连上本机 Zotero。在线获取正文还取决于插件配置的地址和当前网络。换电脑、从校园网切换到家庭网络，或批次频繁停在人机验证时，先用一篇论文测试。

1. 在当前电脑上先试网页。 插件 2.0.1 默认使用 https://sci-hub.ru/，其设置页给出的备用入口为 https://sci-hub.box/，可能跳转到区域镜像。其他历史镜像包括 https://sci-hub.st/ 和 https://sci-hub.se/。可达性会随网络和时间变化。在实际运行批次的网络上，用同一篇开放获取论文的 DOI（例如 10.1371/journal.pmed.0020124）测试能否打开对应论文页，选择访问稳定、较少反复要求人工验证的入口。遇到证书异常请跳过该地址。插件发布页（https://github.com/ethanwillis/zotero-scihub/releases/tag/v2.0.1）
2. 在专用 Zotero 中配置。 从 Literature Desk 点「连接专用 Zotero」，在它打开的 Zotero 窗口进入「编辑 → 设置」，找到 Sci-Hub 插件设置，将选好的根地址（例如 https://sci-hub.ru/）填入 Sci-Hub URL。Sci-Net URL 用于另一个后备服务，保留原配置即可。保持 Automatic PDF Download 关闭，让 Literature Desk 按队列逐篇调度。
3. 用一条题录验证实际下载。 选一篇带 DOI、专用库和本地目录里都没有正文的开放获取论文，运行后点「导出交付」。逐条结果的 method 为 downloaded 且导出的 PDF 能打开，说明这次插件下载和正文核验均已成功。浏览器和 Zotero 的验证会话可能不同；若批次因验证暂停，在专用 Zotero 手动完成验证，再回到 Literature Desk 点「继续」。
