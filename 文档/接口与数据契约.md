# 接口与数据契约 v1（拟定）

### 输入、标识与映射

| 实体 | 必需信息 | 约束 |
|---|---|---|
| Batch | batch_id、创建时间、目标库、输入及映射版本 | UUID；一次确认后固定，重启复用 |
| Source / Group | source_id、原文件名、格式、SHA-256、group_id、导出前缀、目标父子分类 key 或待创建名称 | 一个输入默认一个组；同名文件分别编号。映射到同一分类也保留原组。创建前显示库和父路径供确认 |
| Record | record_id、source_id、group_id、原始顺序、定位信息、全部原字段、work_id | 标识由批内来源与原始顺序确定，重复引用键或来源记录号也有独立行。Bib 保留引用键、原文片段、编码及宏定义；Excel 保留工作表、原行号、来源记录号、列顺序和原单元格 |
| Work | work_id、规范 DOI/PMID、题名、作者、年份、归并依据、冲突状态 | 稳定内部 ID，外部标识可补全。DOI 原值及 URL 并存。仅从可识别的 PubMed 链接提取数字 PMID。相同可靠 ID 或有来源的唯一 DOI↔PMID 对应可归并；两个标识互相矛盾、题名明显冲突或只有同名线索时分开待审 |
| Binding / Candidate | work_id、library_id、item_key、collection_keys、attachment_key 或本地路径、候选来源 | 先查目标库；匹配项有歧义则交人选择。路径或附件 key 只定位候选。桌面读取时文件不可用则记录原因 |

导入时将输入快照存入用户批次工作区并计算指纹，以备恢复和原格式导出。默认读 Excel 用户选定的数据表和所有非空题录行，不因“是否纳入”或“分工”自动过滤。首版按一文件一张数据表导入，表名和首行表头由预览确认。缺少 DOI 的论文可凭 PMID 复用；若需 DOI 才能调度，先用批内可信对应，仍缺则允许人工补充并记录依据，保留 PMID 导出。任何无法解析或无法无损导出的内容在预览中定位到文件、行或条目，禁止静默漏行。

### 本地交换

共享目录含 handshake、commands、receipts。每份消息为 UTF-8 JSON 对象。生产者先在目标目录写临时文件、刷新、关闭，再原子改名。消费者只读完成命名的文件。命令和回执不可变，工作区 SQLite 仅由桌面端写。每次启动握手回显本次 nonce，返回 protocol_major/minor、桥接/Zotero/Sci-Hub 版本、库标识、支持操作及插件函数探测结果。协议主版本不符、库不符或缺少必需能力时，在界面显示具体修复项并阻止对应写操作。

| 方向 / 操作 | 请求载荷 | 回复与语义 |
|---|---|---|
| EXE → XPI：catalog | 目标库 | 父子分类 key、名称、父 key |
| bind | work_id、元数据、库、目标分类列表 | 返回条目 key、实际分类 key 和附件列表；按稳定操作 ID 记录绑定，重复提交须重查现状 |
| list_candidates | 库、条目 key | 返回附件 key、本机可读路径、类型和存在状态；联机存储的占位符应提示同步 |
| acquire | work_id、条目 key、DOI、attempt_id | 返回候选、未找到、需人工验证、能力不支持或结果未知；包含错误原因及是否允许重试 |
| pause / resume | 批次、控制序号、恢复目标 | 暂停立即阻止派发下一项，桥接确认当前项完成或等待人工后报告停点；恢复核对停点后继续 |

通用信封含 schema_version、batch_id、command_id、操作、UTC 时间及 payload；回执另含 command_id、event_seq、status、reason_code 和 data。command_id 对同一逻辑请求稳定，显式重试才发新 attempt_id。桌面按 (command_id,event_seq) 去重，在同一事务内更新状态和已消费位置。桥接逐命令保存受理及完成回执。控制消息走独立轮询，等待验证时也能暂停。未知主版本或损坏 JSON 保留现场，界面指向文件并挂起该项。

### 锁、恢复和核验

桌面端按当前用户持有单实例 Windows 命名互斥锁；桥接端按共享目录持有独占系统文件锁至关闭。两侧锁覆盖整个处理期。心跳显示活性，不凭过期时间抢锁。操作系统释放崩溃进程持有的锁后，重启方先检查批次、目标库及在途命令。桥接锁的实际跨进程排他能力列入联通试验，未验证前禁止多实例运行。

批次依次为草稿、就绪、执行中、暂停中、已暂停、结算、已交付。论文从待绑定、检查本地候选进入已核验或待下载，下载返回候选后再核验。已核验状态保存文件哈希、核验方式及证据。未找到、错件、缺标识和标识冲突分别记录原因，自动转到下一项。

**暂停与继续。** 每次尝试保存 attempt_id、当前论文、最近进展和插件返回结果。批次暂停后停止派发新任务，保存当前请求和剩余队列。程序重启、网络恢复、插件重连或验证窗口关闭后均保持暂停。用户点击“继续”时核对当前请求的回执及附件，再从未完成项接着运行。

遇到人机验证或下载通道已无法推进时，界面显示当前条目及可获得的插件提示，交由用户处理。单篇明确返回未找到时记录缺件并继续队列。

插件受理后、回执落盘前崩溃时，重启重查条目、分类关系及附件变化。新增条目和稳定操作标记应同一 Zotero 事务提交；无法唯一重建绑定则交人选择。下载外部副作用无法保证恰好一次，未决请求先盘点附件，结果仍未知则显示“待确认重试”。写入中断留下的临时文件不消费。交付先在同卷临时快照写全 PDF、清单和汇总，复核哈希和计数后改名发布为新快照；重启保留上次完整交付，可从已核验文件重新结算。

同一核验器处理本地与下载候选，检查文件可打开并能读页、首页题名与标识符或作者年份相符、正文内容充分。排除错文、只在参考文献出现目标 DOI、摘要、目录、补充材料和损坏文件。可读性通过但自动证据不足的扫描件、短文及非英文正文进入人工复核；记录判定、理由和时间。错误候选保留在原处，继续检查其他候选。

### 交付快照

- 正文PDF/ 每个已核验 work_id 一份，使用稳定 work_id 命名，记录相对路径及 SHA-256。两个组的同篇记录引用同一路径。
- 未下载题录/ 按原组和扩展名保存缺件，保持源顺序。Bib 从保留的原文及所需宏重建；Excel 按原列、类型、值及公式保留所有字段，含分工等非书目列。公式依赖其他行或工作表且无法保持含义时须在导入预览明示并阻止有损导出。
- 默认前缀为文件主名；末尾“-数字”符合来源条数时去掉该段，预览允许修订。add_1-589.bib 有 588 条取得时生成 add_1-588-1.bib。不同来源的前缀和扩展名相撞时，预览分配唯一前缀并记录。零缺件组只列汇总，无空缺件文件。
- 分组汇总.csv 每组一行，含原文件名、原始条数、本地复用条数、新下载条数、已取得条数、未取得条数和缺件文件名。组内及跨组均按原记录计；另列全批唯一论文和唯一 PDF 数。
- 逐条结果.jsonl 使用 UTF-8，每个 record_id 一行。固定字段见下方虚构示例。字段缺值用 null，状态枚举为 obtained、missing、review、pending；后三者在用户选择按当前状态结算时均进入未下载题录。获取方式为 local 或 downloaded。后续补下载按 work_id 聚合，回填先核对 source_sha256，再用 source_id、来源定位和 record_id 找到原记录。

```json
{"schema_version":"1.0","batch_id":"B1","source_id":"S1","source_name":"示例.xlsx","source_sha256":"<源文件摘要>","group_id":"G1","record_id":"S1:2","locator":{"sheet":"纳入记录","row":2,"source_record_no":"A01"},"work_id":"W1","title":"示例题名","doi":null,"pmid":null,"library_id":1,"item_key":null,"status":"review","reason_code":"identity_conflict","method":null,"pdf_path":null,"pdf_sha256":null,"verified_at":null}
```

Bib 的 locator 为 cite_key 和 ordinal。取得行必须有 method、pdf_path、pdf_sha256、verified_at；其余行上述字段为 null，并须有原因，如 no_doi、not_found、wrong_attachment、verification_pending 或 interrupted。导出时逐组验证“原始条数＝已取得＋未取得”，逐批验证清单行数等于原始题录总数、取得行的唯一路径集合等于实际交付 PDF 集合。
